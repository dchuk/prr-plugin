# prr

A [Claude Code](https://docs.anthropic.com/en/docs/claude-code) plugin based on *Product Roadmaps Relaunched* by C. Todd Lombardo.

Strategic product roadmapping guidance based on Product Roadmaps Relaunched — shifting from feature-date lists to outcome-driven, theme-based roadmaps that communicate strategy and rally stakeholders.

## Install

```bash
claude plugin add <OWNER>/<REPO>
```

*Replace `<OWNER>/<REPO>` with the GitHub repository (e.g. `your-github-username/prr`) after publishing with `franklin push`.*

## Commands

| Command | Purpose |
|---------|---------|
| `/prr:build-roi-scorecard` | Build an ROI prioritization scorecard for a set of roadmap themes or features. |
| `/prr:transform-features-to-themes` | Transform a list of feature requests or deliverables into outcome-oriented roadmap themes. |
| `/prr:run-shuttle-diplomacy` | Plan and execute shuttle diplomacy sessions for roadmap alignment. |
| `/prr:evaluate-special-request` | Evaluate a special stakeholder request against the current roadmap using the three qualifying questions. |
| `/prr:assess-roadmap-health` | Run the Roadmap Health Assessment by walking through the 14-question checklist (scored 0–2, max 22 points), including subtract-for-overpromising and subtract-for-overdesigning criteria. |
| `/prr:build-roadmap-from-vision` | Construct a roadmap skeleton from company vision down to themes. |
| `/prr:communicate-roadmap-change` | Draft a roadmap change communication for stakeholders. |

## Agents

- **roadmap-reviewer** — Review a product roadmap artifact (document, slide deck description, or structured text) against the book's principles, rules, and anti-patterns.
- **roadmap-relaunch-planner** — Plan a roadmap relaunch or improvement initiative for a given organization.
